Reviewer run 2026-09-12 over `547cb8b..f149a3f` (lane commits `df0ae8b db2c2b8 1d4ad34`).
Method, three probes:
- **Rule 5:** every baseline-touched gate ran with NO config over a scratch copy of each of the 12
  fixture repos, once on `547cb8b`'s `src/` (extracted with `git show`) and once on HEAD's. 72 runs
  (39 of them exit 1), output digests identical.
- **Rule 4:** seven bad `baseline`/`exclude_prefixes` values through the CLI; zero census on all
  seven gates.
- **The ratchet:** read `core/baseline.py` against `tests/test_baseline.py`'s six-gate probe.

**Verdict: HOLD.** The mechanism is right and cheap: one shared ratchet, per file, only shrinks,
and a grown file unfreezes every finding it carries. All seven bad values exit 2 with the key named:
list, absolute, `res://`, `0`, `1.5`, `true`, bare int. All seven zero-census runs FAIL. No config
means byte-identical output. The one MAJOR is scope: the criterion says every per-file gate, and
two such gates ship without a baseline.
