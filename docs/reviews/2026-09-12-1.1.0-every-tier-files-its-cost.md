## Blockers

- `MJ2` MAJOR `src/godot_devkit/godot/installables/gdk_runners.sh:411`
  `( . "$GDK_GATE_LIB" && "$@" )`. The subshell inherits the runner library's own `gdk_gate_log` and
  `gdk_gate_verdict`. So if the sourced file does not redefine them, `"$@"` calls the runner's
  version, which calls `_gdk_cost_row` again, and the recursion continues until `fork` fails. The
  triggers are an empty file, `GDK_GATE_LIB` pointed at `gdk_runners.sh` (its guard returns early),
  or a future agentic-sdlc that renames the two functions. The run still exits 0 and prints PASS
  while the user's process table is exhausted. Observed: `gdk_runners.sh: fork: Resource
  temporarily unavailable` ×2. The safe repro sources a depth-capped stub that defines nothing and
  prints depths 1..5 twice. Fix: `( unset -f gdk_gate_log gdk_gate_verdict; . "$GDK_GATE_LIB" &&
  "$@" )`, plus a stub-library row in the existing unit-row case in `tests/test_runners_installable.py`.

- `N5` NIT: `export GDK_GATE_VERDICT` (and `export GDK_GATE_CENSUS`, `unit.sh:368`) is unnecessary,
  because the `( … )` subshell sees unexported variables. It also leaks `GDK_GATE_VERDICT=FAIL` into
  every Godot/GUT child, where a nested `gdk_gate` would file it ("GDK_GATE_VERDICT wins").

  `GDK_LEDGER_TIMEOUT=30`) after every verdict. With a cold cache and no network, `make unit` can
  stall up to 30s. That is the same price as every wrapped gate, but the CHANGELOG does not say it.
