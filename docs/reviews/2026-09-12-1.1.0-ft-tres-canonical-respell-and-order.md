## Blockers

- `MJ1` MAJOR `src/godot_devkit/godot/format/value_spelling.py:84-85,248`. The positional window
  `[1e-4, 1e6)` is `%g`'s 6-digit fixed range. The saver this module models (shortest round trip,
  the corpus's `6.2831855`) picks exponent form whenever it is SHORTER: d×1e-4 -> `1e-04`,
  d×1e5 -> `1e+05`. The tool rewrites `1e-04`->`0.0001`, `1e+05`->`100000.0`, `2e+05`,
  `5e-04` and `Vector2(1e-04, 1e+05)`, and `check canonical` reports each one as DRIFT. If the saver
  writes the exponent form, these are a legitimate-looking wrong write and a gate that reddens
  saver-written files. Repro: `PYTHONPATH=src python3 -c "from godot_devkit.godot.format.value_spelling
  import canonical_float as c; print(c(1e-4,'variant'), c(1e5,'variant'))"` prints
  `0.0001 100000.0`. The fix is cheap and refuses rather than proves: never rewrite an
  exponent-spelled token, return None for a single-significant-digit value in the 1e-4 or 1e5
  decade, and add both rows to `FloatSpelling`'s table.
