## Blockers

- `M1` MAJOR `src/godot_devkit/godot/checks/test_shape.py:437-447`: a ledgered scenario that
  carries only `## covers: systems/renamed_away` (not in the tree) or `## covers: /abs/nope, res://x`
  now exits 0 with no finding. At `2b37827` the same file was reported (`HEADED` + `HEADER … covers
  \`systems/renamed_away\`, which is not in the tree`). The runner's `--diff` slices by exactly this
  line. A stale entry therefore drops the scenario from every slice, and the runner still does not
  print it as `UNDECLARED`, because a non-empty covers field is not "undeclared". The result is
  real drift under a PASS, on exactly the covers-slicing trees this fix exists to admit. That is
  why this is MAJOR and not MINOR: rule 4. **Fix:** in the held branch, hold only the MISSING line.
  Emit `header_defects(root, body)` minus the `no \`## <key>\` line` defect for the absent key, so a
  present `covers:` still meets the runner's grammar and exists, and a present `Boots` still names
  a `tests/` path. Add the stale-covers held case to the same amended test, not a new one.
