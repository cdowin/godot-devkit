## The fixes

- **`e14f4bd`** (header M1). A held file now has every defect checked except the missing line
  (`test_shape.py:451-457`, `MISSING_LINE_DEFECTS`). The frozenset is built from the same f-strings
  `header_defects` emits, so the two cannot drift apart silently. A drift would re-open M1, and the
  amended case catches it. No new defect.
- **`2608ba0`** (parse M1 and m2). The shim records `$PPID`, which is the `timeout`, because
  `gdk_run_bounded` runs it as a child. GNU timeout forwards TERM to its own group and arms
  `--kill-after` on any caught signal, so the wrapper's `sleep 30` dies (probe above). The pidfile
  is written before the engine can print anything, so the watch cannot read it empty.
  `gdk_stop_bounded` is gone, with no leftover reference in `src/`, `tests/`, README or CHANGELOG
  (only the lane review quotes it). m2's anchor matched 2 of 4 sample lines: both real Godot
  shapes, not a mid-line quote, and not an ANSI-prefixed line (N3).
