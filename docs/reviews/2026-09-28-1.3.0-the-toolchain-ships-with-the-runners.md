Findings:
- `MN2` MINOR `ci-godot-toolchain.yml:105`. Lens zero: the import is a second engine-boot path.
  It is raw and has no bound. The kit already ships `import_cache.sh` (`make import-cache`),

  setup-godot also puts `godot` on `PATH`, which is what `GDK_GODOT` defaults to. A hung
  `--import` can hold the runner until the job timeout. The brief chose this step, so the owner
  decides. Fix: `run: make import-cache`, then the `test -f` assert.
